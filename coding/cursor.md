# Cursor

> An AI-first code editor (a VS Code fork) built around chatting with your codebase — the AI sees your whole project, not just the open file.

**Category:** Coding assistants · **Official site:** https://www.cursor.com

## What it is
An AI-first code editor (a VS Code fork) built around chatting with your codebase — the AI sees your whole project, not just the open file.

## Best for
Working in large codebases, refactoring, onboarding onto unfamiliar code, agentic coding tasks.

## Pricing
Free tier with limited AI requests; Pro (~$20/mo) for much higher usage.

## How to use it
1. Download from cursor.com and open your project folder.
2. Press Ctrl+K for inline edits ('convert this to async'); Ctrl+L to chat about selected code.
3. Use '@' to reference specific files so the AI reads them.
4. Try Agent mode for multi-step tasks: 'add validation to the signup form and write tests.'

## Prompting tips
- Give the agent a tight, verifiable goal and let it work; review the diff after.
- Point it at your existing patterns: 'follow the style in auth/login.py.'

## Gotchas
- Agent mode can make sweeping changes — always review diffs before accepting.
- Burns through AI requests fast on big tasks; watch your usage.
