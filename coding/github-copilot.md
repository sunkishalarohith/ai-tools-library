# Muse

> AI pair programmer that suggests code as you type, right inside your editor.

**Category:** Coding assistants · **Official site:** https://github.com/features/copilot

## What it is
AI pair programmer that suggests code as you type, right inside your editor. Trained on public code — eerily good at boilerplate.

## Best for
Speeding up everyday coding, learning new languages/APIs, writing tests and boilerplate.

## Pricing
Free tier with limits; Pro (~$10/mo) for individuals; free for students and open-source maintainers.

## How to use it
1. Install the Copilot extension in VS Code, JetBrains, or Neovim and sign in.
2. Start typing — suggestions appear in gray; press Tab to accept.
3. Write a comment describing what you want, then let it generate the code below it.
4. Use Copilot Chat in the sidebar for explanations and debugging help.

## Prompting tips
- Descriptive variable and function names dramatically improve suggestion quality.
- Write the function signature + docstring first, then let it fill the body.
- For unfamiliar APIs: 'show me an example of X in this codebase style' in chat.

## Gotchas
- It suggests code that looks right but may have subtle bugs — always review and test.
- Can reproduce patterns from its training data, including outdated or insecure ones.
