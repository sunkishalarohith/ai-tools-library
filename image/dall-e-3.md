# DALL-E 3

> OpenAI's image model, built into ChatGPT.

**Category:** Image generation · **Official site:** https://openai.com/index/dall-e-3

## What it is
OpenAI's image model, built into ChatGPT. Best at following complex, detailed prompts literally — including text in images.

## Best for
Images from detailed descriptions, logos/memes with readable text, quick illustrations inside a ChatGPT conversation.

## Pricing
Included with ChatGPT Plus (~$20/mo); API is pay-per-image.

## How to use it
1. In ChatGPT, just ask: 'generate an image of…' — no special syntax.
2. Describe the scene conversationally; DALL-E 3 understands long, detailed prompts.
3. Ask for revisions in plain language: 'make the sky sunset-orange.'

## Prompting tips
- Write prompts like you're describing to a person: subject, setting, lighting, mood, style.
- For text in images, put the exact words in quotes in your prompt.

## Gotchas
- Less artistically striking than Midjourney for pure aesthetics.
- Photorealistic faces can look slightly artificial.
