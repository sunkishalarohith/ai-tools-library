# FLUX

> Black Forest Labs' open-weights image model — top-tier photorealism and the best hands/anatomy in the business.

**Category:** Image generation · **Official site:** https://blackforestlabs.ai

## What it is
Black Forest Labs' open-weights image model — top-tier photorealism and the best hands/anatomy in the business. A favorite of power users.

## Best for
Photorealistic images, correct anatomy, running locally or via API without per-image subscriptions.

## Pricing
Open weights (free to run); hosted/API options charge per image.

## How to use it
1. Run locally via ComfyUI or Fooocus with a FLUX checkpoint (needs a strong GPU).
2. Or use hosted options (Replicate, Fal.ai, Together) pay-per-image.
3. Prompt like Midjourney but more literal — FLUX follows instructions closely.

## Prompting tips
- FLUX.dev is the most prompt-faithful variant; FLUX.schnell is fastest.
- Excellent at tricky anatomy — good first choice for realistic people.

## Gotchas
- The full model is huge (~24GB) — local use needs serious VRAM or the smaller schnell variant.
