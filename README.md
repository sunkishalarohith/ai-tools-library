# 📚 AI Tools Library

**An open, plain-language library of AI tools — what each one does, how to use it, and how to prompt it well.**

AI tools ship faster than anyone can keep up with. This library exists so you don't have to learn each one the hard way: every entry follows the same format — *what it is, what it's best for, pricing, how to use it, prompting tips, and gotchas.*

## 🚀 Start here if you're new

1. **Pick one chat assistant** — [ChatGPT](llms/chatgpt.md) or [Claude](llms/claude.md). Learn to prompt well; every other tool builds on this skill.
2. **Add one maker tool** for what you create most — [Midjourney](image/midjourney.md) for images, [Suno](audio/suno.md) for music, [Cursor](coding/cursor.md) for code.
3. **Read the prompting tips** in each entry before you pay for anything — good prompting is worth more than a subscription.
