# Contributing to the AI Tools Library

Thanks for helping keep this library current! AI tools change fast, so contributions are what keep it useful.

## How to contribute

1. **Fork** the repo and create a branch.
2. **Add or update** a tool entry (see format below).
3. **Open a pull request** with a short description of what changed.

## Adding a new tool

1. Pick the right category folder (`llms/`, `coding/`, `image/`, `video/`, `audio/`, `productivity/`). If none fits, propose a new one in your PR.
2. Copy [template.md](template.md) to `<category>/<tool-slug>.md`.
3. Fill in every section. Keep it plain-language — write for a smart beginner.
4. Add the tool to the category list in [README.md](README.md).

## Updating an existing tool

Small fixes (pricing changes, new features, dead links) are the most valuable contributions. Just edit the file and open a PR — no need to ask first.

## Ground rules

- **No invented details.** Only write what you can verify on the tool's official site or docs. When in doubt, link to the source instead of guessing.
- **No sponsored content.** Don't add tools to promote them; add them because they're genuinely useful and widely used.
- **Keep the format.** Every entry needs all six sections: what it is, best for, pricing, how to use, prompting tips, gotchas.
- **Be honest about downsides.** The "Gotchas" section is mandatory — every tool has them.
