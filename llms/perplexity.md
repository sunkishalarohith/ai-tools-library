# Perplexity

> An AI search engine that answers questions with cited sources instead of a link list.

**Category:** Chat / LLMs · **Official site:** https://www.perplexity.ai

## What it is
An AI search engine that answers questions with cited sources instead of a link list. Think ChatGPT crossed with Google, with footnotes.

## Best for
Research, fact-checking, staying current on news, shopping comparisons, anything where sources matter.

## Pricing
Free tier with limited 'Pro' searches per day; Pro (~$20/mo) for more searches and model choice.

## How to use it
1. Type a question like a search query — it returns an answer with numbered citations.
2. Click the citations to verify claims against the original sources.
3. Use Focus modes (Web, Academic, Social) to narrow where it looks.

## Prompting tips
- Ask follow-ups in the same thread to drill deeper: 'what do critics of this say?'
- For shopping or travel, ask for a comparison table with prices and links.

## Gotchas
- Answers are only as good as the sources it finds — weak sources, weak answer.
- Not a replacement for reading the actual article on important topics.
